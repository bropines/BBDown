# Документация JSON API

## API

При запуске BBDown в режиме сервера программа запускает локальный HTTP-сервер со следующими API-интерфейсами:

### Получить список задач
**Эндпоинт:** `/get-tasks/`

**Метод:** GET

**Описание:** Получить список всех задач, включая активные и завершенные.

**Ответ:** Объект `DownloadTaskCollection` в формате JSON.

### Получить список активных задач
**Эндпоинт:** `/get-tasks/running`

**Метод:** GET

**Описание:** Получить список всех выполняющихся в данный момент задач.

**Ответ:** Объект `List<DownloadTask>` в формате JSON, список активных задач.

### Получить список завершенных задач
**Эндпоинт:** `/get-tasks/finished`

**Метод:** GET

**Описание:** Получить список всех завершенных задач.

**Ответ:** Объект `List<DownloadTask>` в формате JSON, список завершенных задач.

### Получить конкретную задачу
**Эндпоинт:** `/get-tasks/{id}`

**Метод:** GET

**Описание:** Получить подробную информацию о конкретной задаче по значению AID видео.

**Параметры:**
- `{id}` (параметр пути): AID видео.

**Ответ:** Если соответствующая задача найдена, возвращается объект `DownloadTask` в формате JSON. Если задача не найдена, возвращается код ответа `404 Not Found`.

### Добавить задачу
**Эндпоинт:** `/add-task`

**Метод:** POST

**Описание:** Добавить новую задачу в список загрузок.

**Тело запроса:** JSON-объект параметров задачи, соответствующий структуре `MyOption`. Передавать все поля `MyOption` не обязательно, достаточно указать только поле `Url`.

**Ответ:**
- Если запрос корректен и задача успешно добавлена, возвращается код `200 OK`.
- Если запрос некорректен, возвращается код `400 Bad Request` с сообщением об ошибке `"输入有误"` (некорректный ввод).

### Удалить завершенные задачи
**Эндпоинт:** `/remove-finished`

**Метод:** GET

**Описание:** Удалить все завершенные задачи из списка.

**Ответ:**
- Возвращается код `200 OK`.

### Удалить неудачные завершенные задачи
**Эндпоинт:** `/remove-finished/failed`

**Метод:** GET

**Описание:** Удалить все завершенные задачи, которые завершились сбоем (`IsSuccessful == false`).

**Ответ:**
- Возвращается код `200 OK`.

### Удалить конкретную завершенную задачу
**Эндпоинт:** `/remove-finished/{id}`

**Метод:** GET

**Описание:** Удалить конкретную завершенную задачу по значению AID видео.

**Параметры:**
- `{id}` (параметр пути): AID видео.

**Ответ:**
- Возвращается код `200 OK` независимо от того, найдена ли задача с таким ID.

## Структуры данных

### Структура `DownloadTask`
Структура `DownloadTask` представляет информацию о задаче загрузки.

**Свойства:**
- `Aid` `<string>`: Распознанный AID видео. Служит уникальным идентификатором активных задач. В списке завершенных задач допускаются дублирующиеся значения.
- `Url` `<string>`: URL-адрес, переданный при создании задачи. Поддерживаются как полные URL-адреса Bilibili, так и форматы `av|bv|BV|ep|ss`.
- `TaskCreateTime` `<long>`: Время создания задачи (Unix-таймштамп в секундах, локальный часовой пояс).
- `Title` `<string?>`: Название видео.
- `Pic` `<string?>`: Ссылка на обложку видео.
- `VideoPubTime` `<long?>`: Время публикации видео (Unix-таймштамп в секундах).
- `TaskFinishTime` `<long?>`: Время завершения задачи (Unix-таймштамп в секундах, локальный часовой пояс).
- `Progress` `<double>`: Прогресс выполнения задачи, значение с плавающей точкой в диапазоне от `0.0` до `1.0`.
- `DownloadSpeed` `<double>`: Скорость скачивания в байтах в секунду (Б/с). Во время скачивания отображается скорость последнего обновления, после завершения — средняя скорость за всё время.
- `TotalDownloadedBytes` `<double>`: Общее количество скачанных байт. Итоговое число может быть немного меньше реального размера файла.
- `IsSuccessful` `<bool>`: Флаг, указывающий на успешное завершение задачи.

### Структура `DownloadTaskCollection`
Структура `DownloadTaskCollection` содержит два списка, представляющих активные и завершенные задачи.

**Свойства:**
- `Running` `<List<DownloadTask>>`: Список выполняющихся задач.
- `Finished` `<List<DownloadTask>>`: Список завершенных задач.

### Структура `MyOption`

Обратитесь к файлу [BBDown/MyOption.cs](./BBDown/MyOption.cs). Свойства структуры практически один к одному соответствуют параметрам командной строки. Передавайте те же значения, что и для CLI. Структура может меняться в зависимости от версии программы, проверяйте актуальный код для вашей версии.

### Примечания
- Из-за особенностей периодичности обновления прогресса в BBDown значение `TotalDownloadedBytes` может быть немного меньше фактического размера файла (примерно на объем данных, скачиваемых за 1 секунду). На очень маленьких файлах погрешность будет более заметной.
- Во внутреннем движке BBDown нет надежного механизма отмены отдельной задачи. После добавления задача будет выполняться до завершения или до возникновения ошибки.
- В настоящее время сервер не ограничивает количество одновременно запущенных задач. Если вы добавите много задач за короткое время, они будут выполняться параллельно. Следите за тем, чтобы не исчерпать ресурсы системы. В будущем планируется добавить очередь загрузок.
- Сервер API не имеет встроенной поддержки протокола HTTPS. При необходимости настройте обратное проксирование через nginx или аналогичные решения.
- В режиме сервера списки задач защищены блокировками при параллельном доступе, но глобальные учетные данные в `Config` разделяются между одновременно выполняющимися задачами.

### Примеры использования

#### Добавить задачу по BVID

```shell
curl -X POST -H 'Content-Type: application/json' -d '{ "Url": "BV1qt4y1X7TW" }' http://localhost:58682/add-task
```

#### Загрузка в определенную директорию

Windows:
```shell
curl -X POST -H 'Content-Type: application/json' -d '{ "Url": "BV1qt4y1X7TW", "FilePattern": "C:\\Downloads\\<videoTitle>[<dfn>]" }' http://localhost:58682/add-task
```

Unix-Like:
```shell
curl -X POST -H 'Content-Type: application/json' -d '{ "Url": "BV1qt4y1X7TW", "FilePattern": "/Downloads/<videoTitle>[<dfn>]" }' http://localhost:58682/add-task
```
